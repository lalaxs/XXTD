# 《仙侠合成塔防》攻击法宝与肉鸽技能设计文档

> 状态：设计定稿，尚未实现。
>
> 本文档是当前 15 把攻击法宝的特效、Q1～Q9 品质成长、专属肉鸽技能及统一结算规则的权威规格。每把武器将分别配置 Q1～Q9 的数值攻击力，具体数值表尚未设计，后续将按武器机制强弱单独制定。
>
> **攻击力定义**：每把武器的每个品质分别配置一个“品质配置攻击力”，这是该品质的原始数值。进入战斗后，先由品质配置攻击力乘以当前境界攻击倍率，形成“当前武器攻击力”；明确作用于该武器的局内武器增伤也在这一层结算。除技能明确写明读取“最终伤害”或其他特殊属性外，所有“武器伤害 × X%”均以当前武器攻击力为计算基准，因此境界攻击倍率会同时放大主攻击和此类武器特效。暴击倍率、敌人防御、易伤、护盾及实际生命损失属于后续结算，不反向改变当前武器攻击力。
>
> ```text
> 当前武器攻击力 = 品质配置攻击力 × 境界攻击倍率 × 适用的局内武器增伤修正
> 武器特效基础伤害 = 当前武器攻击力 × 技能比例
> ```

# 2. 全局规则

## 2.1 品质成长采用累计制

每把武器最高可合成为 Q9。品质效果采用累计制：

- Q1～Q3 获得的效果在 Q4～Q9 继续保留；
- Q4～Q6 获得的效果在 Q7～Q9 继续保留；
- Q7～Q9 是武器机制的高阶强化；
- 表格中的“每级 +X%”若无特殊说明，表示增加 X 个百分点。

例如青锋剑：

- Q1 暴击率 +5%；
- Q2 累计 +10%；
- Q3 累计 +15%；
- Q4 保留 +15% 暴击率，并开始强化高血追加伤害。

## 2.2 Q1～Q3 的统一成长

采用统一低品质淬炼规则：

- 除碧水剑外，大部分武器 Q1～Q3 每级暴击率 +5%；
- 碧水剑必定暴击，因此 Q1～Q3 每级暴击伤害 +5 个百分点。

## 2.3 肉鸽技能规则

每次境界突破后的肉鸽奖励始终分为三个相互独立、依次进行的阶段：

1. 攻击法宝三选一；
2. 防御法宝三选一；
3. 敌方强化三选一。

三个阶段拥有各自独立的候选池，不混合抽取。攻击法宝的 58 个唯一专属技能只进入攻击法宝阶段；防御奖励和敌方强化分别进入其对应阶段。

除技能明确规定的全场、溅射、穿透、追击、溢出传播或目标转移外，所有武器默认攻击**同列距离玩家最近的存活敌人**。若同列同时存在多个合法目标，按距离玩家的行号从近到远选择；场上随机奖励不属于敌人目标，只有技能明确允许攻击奖励时才参与目标选择。

- 必须拥有对应武器，才能解锁该武器的专属肉鸽技能；
- 每个具名肉鸽技能本局最多选择一次，不能重复选择；
- 同一把武器的不同专属技能可以分别获得；
- 已选择技能从本局后续候选池中移除；
- 同一次三选一中，同一把武器最多出现一个专属技能；
- 双武器联动技能必须同时拥有指定武器才能出现；
- 共享技能使用同一个奖励 ID，在不同武器候选池中不能重复获得；
- 肉鸽奖励属于本局构筑，局终或轮回时清空。
- 境界突破不清除当前棋盘上的残留怪物，也不清除场上随机奖励；突破只执行即时全额回血、修为清零、天赋点发放和肉鸽阶段流程。

## 2.4 暴击相关定义

### 普通暴击

```text
暴击伤害 = 武器伤害 × 当前暴击倍率
```

普通暴击可以触发“暴击后”能力。

### 暴击触发的独立伤害

部分能力需要本次攻击先暴击，但附加伤害采用独立公式，不属于暴击伤害。例如缚妖链“狂怒”：

```text
狂怒伤害 = 武器伤害 × 3
```

狂怒由暴击触发，但不使用暴击倍率，也不能再次暴击。

## 2.5 额外攻击

额外攻击默认遵循：

- 是一次新的攻击；
- 可以暴击；
- 可以触发该武器基础被动；
- 可以触发正常命中、状态和击杀效果；
- 不能再次触发生成自己的追击技能；
- 不能形成递归或无限追击。

## 2.6 额外伤害

额外伤害默认遵循：

- 不是一次攻击；
- 默认不能暴击；
- 不计入攻击次数；
- 不触发武器基础被动；
- 不触发追击；
- 不触发生成自身的能力；
- 技能明确写明例外时，按技能描述执行。

## 2.7 持续伤害

持续伤害默认遵循：

- 不计为一次攻击；
- 默认不能暴击；
- 可以击杀敌人；
- 击杀可以触发正常击杀奖励；
- 不能触发攻击型追击或再次施加自身。

## 2.8 控制抗性

### 普通敌人

控制效果正常生效。

### 精英敌人

控制结算顺序：

1. 先进行武器自身的控制触发判定；
2. 触发成功后，精英再进行 50% 控制躲避判定；
3. 躲避成功则不受控制；
4. 躲避失败则正常受控；
5. 只有真正控制成功，才进入控制免疫冷却；
6. 精英躲避可触发“控制失败”类补偿效果。

### 头目敌人

头目完全免疫硬控制：

- 定身；
- 致盲；
- 击退；
- 拉拽；
- 其他无法行动类效果。

头目仍可受到削攻、削防、灼烧、额外伤害及斩杀效果。

## 2.9 敌方强化与武器收益隔离

每次突破第三阶段会强化敌人，因此不得让玩家通过选择敌方强化，反向无成本强化护心珠、白骨杖或破阵枪。

敌人需要区分：

- 原始模板攻击/防御；
- 加入境界、难度和肉鸽强化后的实际攻击/防御。

规则：

- 护心珠削攻作用于实际攻击力，但削攻转伤使用原始模板攻击力计算；
- 白骨杖削防作用于实际防御力，但专属能力读取削防比例，不读取强化后的防御绝对值；
- 破阵枪无视实际防御力，但按防御追加的伤害使用原始模板防御力计算。

## 2.10 多件同类武器

总原则：

> 敌人身上的状态共享，武器自身的计数独立；若某状态明确规定按来源独立结算，则底层按来源保存，Tip 只做汇总显示。

具体规则：

- 赤焰枪每次成功施加的每层灼烧都是一个独立灼烧实例；每个实例独立记录来源武器、初始伤害、当前伤害和剩余持续回合；
- 进行灼烧结算前，先逐个检查灼烧实例的剩余持续回合；剩余回合大于0的实例才产生伤害，剩余回合为0的实例立即移除且不再结算；
- 每个有效灼烧实例使用自己的当前伤害独立结算并四舍五入；随后把所有有效实例的伤害相加，对目标造成一次总灼烧伤害；
- 每个实例结算一次后，其下一次伤害独立衰减为本次伤害的50%，并扣除1回合持续时间；不同实例不共享衰减进度，也不共享持续时间；
- 新施加的灼烧实例从该来源武器计算出的完整初始伤害开始，不继承目标身上旧灼烧的衰减；
- 例如两个实例本次分别造成100和5点伤害，则总伤害为105；下次各自衰减为50和3点，总伤害为53；再次各自衰减为25和2点，总伤害为27；
- 多把缚妖链分别记录连续暴击增伤；
- 多把金光环分别记录击退蓄势；
- 多把镇妖塔共享敌人身上的封印层数；
- 多把紫气葫芦分别记录回血保底；
- 双刃锁链每一段分别结算命中与击杀；
- 清音琴的目标定身免疫状态共享；
- 白骨杖的目标削防状态共享，但各把白骨杖的基础削防不可相加，按本节状态规则处理。

## 2.11 状态显示

与敌人相关的状态、层数、持续时间、控制抗性和触发进度，应显示在敌人详细信息 Tip 中，包括：

- 灼烧按实例显示来源武器、初始伤害、当前伤害和剩余回合；同一来源的多个实例可以分组显示，但不能丢失各实例独立的持续时间与衰减进度；Tip 同时显示本次总灼烧伤害；
- 定身、致盲及控制免疫；
- 削攻、削防及持续回合；
- 镇妖塔封印层数；
- 青锋剑、太极剑阈值是否满足；
- 与当前目标相关的缚妖链连暴、金光环蓄势等信息；
- 精英 50% 控制躲避与头目控制免疫说明。

# 3. 青锋剑

## 3.1 基础特性

攻击当前生命值高于 80% 的敌人时，额外造成武器伤害 20% 的伤害。

该伤害属于额外伤害，默认不能暴击。

## 3.2 Q1～Q9 品质成长

| 品质 | 新增效果 | 累计结果摘要 |
|---|---|---|
| Q1 | 暴击率 +5% | 暴击率 +5% |
| Q2 | 暴击率 +5% | 暴击率 +10% |
| Q3 | 暴击率 +5% | 暴击率 +15% |
| Q4 | 高血额外伤害 +10 个百分点 | 额外伤害 30% |
| Q5 | 高血额外伤害 +10 个百分点 | 额外伤害 40% |
| Q6 | 高血额外伤害 +10 个百分点 | 额外伤害 50% |
| Q7 | 触发阈值 -5 个百分点 | 高于 75% 触发 |
| Q8 | 触发阈值 -5 个百分点 | 高于 70% 触发 |
| Q9 | 触发阈值 -5 个百分点 | 高于 65% 触发 |

## 3.3 专属肉鸽技能

### 太清剑法

共享技能，拥有青锋剑或太极剑时可解锁。

- 只拥有青锋剑：青锋剑同时获得太极剑的基础低血追加伤害；
- 只拥有太极剑：太极剑同时获得青锋剑的基础高血追加伤害；
- 不解锁另一把武器的掉落与合成池；
- 已经同时拥有两把剑时，该能力不再出现。

### 剑露锋芒

共享技能，拥有青锋剑或太极剑时可解锁。

- 青锋剑和太极剑的阈值额外伤害效果提高 20%；
- 采用乘算增幅；
- 青锋剑基础 20% 提高为 24%；
- 太极剑基础 15% 提高为 18%；
- 后续获得另一把剑时，另一把剑也自动获得该强化。

### 锋锐

青锋剑攻击时有 10% 概率额外造成武器伤害 50% 的伤害。

- 不能暴击；
- 不触发青锋剑高血被动；
- 不计为一次攻击。

### 化利

青锋剑高血追加伤害的触发阈值降低 15 个百分点。

例如 Q9 原阈值为 65%，获得后降至 50%。

# 5. 碧水剑

## 5.1 基础特性

- 攻击必定暴击；
- 基础暴击伤害为 110%。

## 5.2 Q1～Q9 品质成长

| 品质 | 新增效果 | 累计结果摘要 |
|---|---|---|
| Q1 | 暴击伤害 +5 个百分点 | 暴击伤害 115% |
| Q2 | 暴击伤害 +5 个百分点 | 暴击伤害 120% |
| Q3 | 暴击伤害 +5 个百分点 | 暴击伤害 125% |
| Q4 | 武器伤害 +5% | 武器伤害累计 +5% |
| Q5 | 武器伤害 +5% | 武器伤害累计 +10% |
| Q6 | 武器伤害 +5% | 武器伤害累计 +15% |
| Q7 | 附加目标最大生命 1% 的伤害 | 受 70% 武器伤害上限约束 |
| Q8 | 附加目标最大生命 3% 的伤害 | 受 70% 武器伤害上限约束 |
| Q9 | 附加目标最大生命 5% 的伤害 | 受 70% 武器伤害上限约束 |

最大生命附加伤害公式：

```text
最大生命附加伤害 = min(
    敌人最大生命值 × 当前品质比例,
    碧水剑武器伤害 × 70%
)
```

该伤害：

- 不能暴击；
- 不触发其他追加效果；
- 不参与“翻江搅海”的溢出伤害；
- 不计为额外攻击；
- 可以正常击杀敌人。

## 5.3 专属肉鸽技能

### 催新浪

碧水剑暴击伤害改为每次攻击独立波动：

- Q1～Q2：90%～150%；
- Q3～Q9：100%～160%。

### 断流

选择“断流”后：

- 碧水剑不再产生暴击标记；
- 每次攻击仍进行一次虚拟暴击判定，得到本次**断流前虚拟暴击伤害**；
- 本次主攻击改为普通攻击，并额外增加断流前虚拟暴击伤害的 10%；
- 断流增加的部分属于主攻击增幅，不是额外攻击，也不是暴击伤害。

```text
断流前虚拟暴击伤害 = 当前武器攻击力 × 本次虚拟暴击倍率
断流增幅伤害 = 断流前虚拟暴击伤害 × 10%
断流后主攻击伤害 = 当前武器攻击力 + 断流增幅伤害
```

例如品质配置攻击力为100、当前境界攻击倍率为1.5、本次虚拟暴击倍率为160%，且无其他武器增伤：

```text
当前武器攻击力 = 100 × 1.5 = 150
断流前虚拟暴击伤害 = 150 × 160% = 240
断流增幅伤害 = 240 × 10% = 24
断流后主攻击伤害 = 150 + 24 = 174
```

### 水势

攻击时额外附加一次等于本次**主攻击最终暴击伤害** 20% 的伤害。

- 未拥有“断流”时，读取本次真实主攻击的最终暴击伤害；
- 与“断流”同时持有时，读取本次断流前虚拟暴击伤害；
- 只读取碧水剑主攻击的真实或虚拟暴击伤害；
- 不计入 Q7～Q9 最大生命附加伤害、其他额外伤害或溢出伤害；
- 不能再次暴击；
- 不触发最大生命附加伤害；
- 不触发其他追加攻击。

例如品质配置攻击力为100、当前境界攻击倍率为1.5、本次断流前虚拟暴击倍率为160%，同时拥有“断流”和“水势”，且无其他武器增伤：

```text

断流前虚拟暴击伤害 = 240
断流后主攻击伤害 = 174
水势伤害 = 240 × 20% = 48
两项合计伤害 = 174 + 48 = 222
```

# 16. 赤焰枪

## 16.1 基础特性

攻击施加灼烧，灼烧可以叠加。

统一灼烧规则：

- 赤焰枪每次成功施加的每层灼烧，都创建一个独立灼烧实例；
- 每个实例的初始伤害使用施加它的赤焰枪当前品质规定比例乘以该武器自身攻击力；
- 每个实例基础持续3回合；
- 同一目标基础最多同时存在5个有效灼烧实例；
- 新增灼烧不会刷新旧灼烧实例，也不会继承旧实例的持续时间或衰减进度；新实例从完整初始伤害和完整持续时间开始；
- 每次结算前先检查每个实例的剩余回合：剩余回合大于0才结算，等于0则移除且不造成伤害；
- 每个有效实例分别造成自身当前伤害，单个实例伤害四舍五入后再汇总为目标本次总灼烧伤害；
- 单个实例每次造成伤害后，其下一次伤害衰减为本次伤害的50%，并把自己的剩余回合减1；
- 不同灼烧实例独立衰减、独立计时、独立结束；某个实例持续时间结束时，只停止该实例伤害，不影响其他仍有效的灼烧；
- 灼烧不能暴击。

## 16.3 专属肉鸽技能

### 火上浇油

- 灼烧最大层数从5层提高至10层；
- 灼烧持续时间增加1回合，即持续4回合。

### 烈火焚身

目标每有一层灼烧，赤焰枪直接攻击伤害提高2%，最多提高30%。

### 爆燃

1. 按剩余持续回合从少到多排序；

# 19. 后续数值设计原则

武器基础伤害和 Q1～Q9 攻击力将在后续单独设计。建议根据特效覆盖率调整面板伤害：

- 特效越稳定、覆盖率越高，基础伤害应越低；
- 特效越依赖生命阈值、连暴、低血或概率触发，基础伤害可以更高；
- 全场伤害、多段攻击、必定暴击、最大生命百分比伤害不能只按单发面板比较；
- 护心珠、白骨杖、清音琴和金光环包含功能性价值，面板伤害需要为控制与减益让出预算；
- 碧水剑最大生命伤害受武器伤害70%上限约束；
- 赤焰枪基础最多5层灼烧，只有获得火上浇油后才提高至10层；
- 镇妖塔需要按场上平均敌人数计算全场总伤害；
- 双刃锁链需要按两段或三段的总倍率计算，而不是按单段伤害计算；
- 灵墨笔需要按玩家生命区间分别评估，而不是只看满血状态。
