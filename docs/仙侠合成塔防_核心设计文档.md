# 《仙侠合成塔防》核心设计文档（实现规格）

> 本文件为当前设计的权威实现规格，供程序落地。所有数值标 `[P]` 者为 playtest 前假设值，需实测调平。

---

# 第一部分：P0 最终方案

## 1. 游戏概述

竖屏回合制**合成塔防**。修仙题材，核心循环：拖拽部署法宝 / 护甲 / 消耗品 → 回合结算自动攻击 → 击杀妖魔获修为 / 击碎场上随机奖励获补给 → 合成升阶 → 修为满后自动突破并获得肉鸽 3 选 1 / 天赋点成长。轮回系统当前为原型配置：函数已存在但完整入口尚未接入主流程；终局通关已在渡劫境最终波清空后触发，并顺序解锁下一难度。

## 2. 战场结构

- 棋盘：5 列 × 9 行（上 7 行怪物区 + 下 2 行部署区）
- **部署格：10 个（2 行 × 5 列）—— 法宝（武器）、护甲道具、消耗品 三者共享这 10 格**（不再有独立护甲栏 / 消耗栏）。
  - 法宝（武器）放其中 → 按列攻击；需摆在对应列才能打到该列敌人。
  - 护甲道具放其中 → 被动提供防御力（与位置无关，占格即生效）。
  - 消耗品（丹药 / 符咒）放其中 → 单击图标下「使用」钮主动使用，用完腾出该格。
- 暂存区：1 个道具位（场上随机奖励被击碎后先入此处，再拖入 10 格）
- **分解区域**：战场侧 / 底部独立一格（「化废炉」），**拖动法宝 / 护甲道具到此处即分解**（转修为，不耗回合）；**消耗品不可拖入分解区**（消耗品靠「使用」消耗，不回收）。

## 3. 玩家操作与交互模型

### 3.1 单击（查看 / 使用，不耗回合）

| 单击对象 | 反馈 | 后续动作 |
|----------|------|---------|
| 法宝（武器） | **浮窗弹出**：显示该法宝全部属性（品质、攻击 / 控制值、词条、流派） | 纯查看；**分解需拖到分解区域**（见 §3.2） |
| 护甲道具 | **浮窗弹出**：显示防御值 / 品质 / 词条 | 纯查看 |
| 消耗道具（丹药 / 符咒） | **图标下方弹出「使用」按钮**（不弹大浮窗） | 点「使用」→ 生效，消耗 1 个，腾出该格（见 §7） |
| 空槽 / 棋盘空白 | 无 | — |

### 3.2 拖动（合成 / 交换 / 分解，耗 1 回合）

```
拖动 A 到目标：
  ├─ 目标 = 分解区域
  │     → A 分解：转对应修为，不耗回合（法宝 / 护甲道具专用；消耗品不可拖入分解区）
  ├─ A、B 同属一大类（法宝武器 / 护甲道具 / 丹药 / 符咒 四选一）且 同品质（目标为 10 格内该类别格）
  │     → 直接合成：大类不变、品质 +1、类型随机（见 §12 盲盒规则）
  │     → 无额外动画表现，落定即生效
  ├─ 否则若 A 来自部署格、目标为部署格
  │     → 交换位置（A 与 B 互换；若目标空则单纯移动）
  ├─ 否则若 A 来自暂存区、目标为空部署格
  │     → 单纯放置
  └─ 否则若 A 来自暂存区、目标为已占用部署格且不可合成
        → 阻止放置（暂存区物品只可放入空部署格，或与目标同大类同品质合成）
```

- **合成判定极简**：只认「同大类 + 同品质」，不认具体类型 → 与盲盒合成天然契合。
- **不能合成时的处理**：部署格之间拖动到不可合成格 = 交换 / 移动；暂存区拖到已占用部署格时，只有可合成才允许落下，不可合成则阻止放置，避免暂存区与部署格互换。
- **分解 = 拖到分解区域**：独立区域，所见即所得，避免误触。
- **无跳过按钮**：必须执行部署操作（放置 / 移动 / 交换 / 合成 / 分解）才推进回合。
- 操作限制：暂存区仅 1 位；最后 1 把武器不可分解（保底输出）；圣品（Q9）不可再合成；分解区域只接受法宝（武器）与护甲道具；消耗品不可分解（只能「使用」）。

### 3.3 操作 × 回合经济总表

| 操作 | 是否耗回合 | 说明 |
|------|-----------|------|
| 暂存区 → 部署格放置 | 是（1） | 改变战场状态 |
| 部署格内移动 | 是（1） | 改变战场状态 |
| 交换两个部署格 | 是（1） | 改变战场状态 |
| 合成（同大类同品质） | 是（1） | 落定即生效 |
| 拖到分解区域 | 否（0） | 法宝 / 护甲道具转修为（消耗品不可分解） |
| 使用消耗道具（使用钮） | 否（0） | 自由动作，受每回合使用上限 `[P]` 约束 |
| 单击查看属性 | 否（0） | 纯观察 |

## 4. 回合结算流程（当前 `TurnEngine` 实现顺序）

```
 1. 玩家决策阶段 —— 本阶段可自由：拖动部署/合成、单击使用消耗道具（不耗回合，受上限约束）
 2. 回合开始 —— `turn + 1`，清空本回合日志 / 伤害事件 / 消耗品使用次数
 3. 护甲回合特效 —— 已部署护甲先结算每回合护盾 / 回血 / 净化 / 免疫等被动效果
 4. 法宝攻击 —— 每把武器按自身攻击模式结算（同列距离优先，见 §5），可攻击怪物或场上随机奖励
 5. 击杀 / 奖励处理 —— 怪物死亡发修为；场上随机奖励被击碎后生成道具并尝试进入暂存区
 6. 远程怪攻击 —— 射程内远程怪先攻击玩家，并可施加玩家 debuff（debuff 延迟到本次伤害结算后生效）
 7. 场上随机奖励移动 —— 奖励下移 1 格；越过第 7 行则消失；奖励只与奖励互相阻挡
 8. 怪物移动 —— 怪物下移 1 格；怪物只与怪物互相阻挡；定身 / 减速等控制在此阶段生效
 9. 近战怪攻击 —— 已在底线蓄力完成的近战怪对玩家造成伤害
10. 玩家承伤与死亡判定 —— 汇总本回合怪物 / 毒伤等伤害，套用护甲防御与减伤；若气血归零，先触发续命丹护佑 / 持有续命丹自动消耗，再进入跌境或游戏结束
11. 天赋回春与状态结算 —— 回春类天赋回血；再次处理死亡怪；怪物 DoT / 易伤 / 定身 / 玩家 debuff / 护甲特效持续时间等状态 tick；再次处理死亡怪
12. 境界/突破检查 —— 修为满自动突破（不耗回合），即时回血、清场、发放突破天赋点，并弹出肉鸽 3 选 1
13. 肉鸽补给触发 —— 若拥有百宝囊等回合型奖励，在指定回合强制刷新场上随机奖励
14. 波次与场上奖励刷新 —— 若未处于肉鸽选择中，按概率/保底刷新场上随机奖励；按波次规则刷新新怪物；本回合若刚清空怪物，则延迟到下回合强制出下一波
15. Buff 计时 —— 本轮 BuffSystem 的局内 buff 统一 tick
```

> 当前实现中，怪物死亡不会直接生成宝箱；补给来自「场上随机奖励」系统。场上随机奖励按概率 / 保底 / 百宝囊等机制刷新，被法宝击碎后把道具放入暂存区。

## 5. 法宝攻击规则（由「飞剑」泛化为「武器」）

- **距离优先**：每把武器攻击**同列距离玩家最近**的目标（不区分怪物 / 场上随机奖励）。
- 每回合结算第 2 步发动 1 次（多武器按列独立结算、叠加）。
- **攻击模式因武器而异**（单体 / 横扫 / 穿透 / 范围 / 控制 / 守护），详见 §15 的 15 把具名法宝映射。
- 跨列攻击基础不可；特定武器模式（横扫 / 范围）按设计覆盖相邻列 / AoE。

## 6. 护甲道具系统（防御池）

**核心定义**：护甲道具是**独立的防御类道具**（非法宝、非消耗品），提供「**防御力**」——对每次受到的伤害做固定减算。**无耐久、无额外血条、无减伤词条**。法宝不再提供防御力；防御力唯一来源 = 护甲道具。

- **来源**：场上随机奖励被击碎后生成补给，**开局不自带护甲**；补给类型取自「已天赋解锁的防御池」（见 §12.3），非全量随机。
- 防御值 = 放入 10 部署格的护甲道具提供的减伤量，**多件叠加（加法）**。
- 伤害结算：`finalHit = max(1, rawDamage - 总防御值)`，且单 hit 减算不超过该次 rawDamage 的 `60% [P]`（防极端叠防让小怪归零）。
- 境界防御倍率（§10）对防御值做全局乘算（高境界护甲更硬）。
- 护甲道具随品质提升防御值（见下表，`[P]` 假设）：

| 品质 | 阶 | 防御值 | 合成所需 Q1 数 |
|------|---|--------|--------------|
| 凡品 | 1 | 6 | 1 |
| 良品 | 2 | 12 | 2 |
| 上品 | 3 | 24 | 4 |
| 精品 | 4 | 48 | 8 |
| 极品 | 5 | 96 | 16 |
| 珍品 | 6 | 192 | 32 |
| 仙品 | 7 | 384 | 64 |
| 神品 | 8 | 768 | 128 |
| 圣品 | 9 | 1536 | 256 |

> 上表为护甲防御值基础曲线；当前实现还会按 P4.4 的护甲家族权重修正实际防御值，例如玄铁宝盾 ×0.85、净秽宝珠 ×0.7，其余护甲当前为 ×1.0。

- 护甲道具走「同大类同品质 → 升阶、类型随机」合成（见 §12），**类型池 = 已天赋解锁的防御池共享池**（默认仅玄铁宝盾，靠天赋解锁其余 4 件）。
- 设计取舍：去掉耐久后，护甲道具是「放上去就一直减伤」的稳态防线，玩家决策从「续耐久」转为「叠几件 / 占几个格」。
- 护甲除通用防御值外，高品还带**防御特效**（格挡 / 反伤 / 护盾 / 回血 / 净化），随品质 Q1–Q9 演进，详见 **P1-3**。

## 7. 消耗道具系统：丹药 / 符咒

**分类**：丹药、符咒归为「**消耗道具**」，**不是法宝也不是护甲道具**，占 10 部署格之一（与法宝 / 护甲共享格子），用完腾出该格。

### 7.1 使用交互（严格按用户定义）
```
玩家单击某消耗品图标（在 10 格中）
  → 该图标正下方弹出「使用」按钮
  → 玩家再点「使用」→ 生效，消耗 1 个，腾出该格
```
- 使用**不耗回合**（自由动作），但受「每回合使用上限 `[P]`」约束，防止一回合全砸完。
- 不在 35% 自动触发；是否用、何时用完全由玩家决定。

### 7.2 丹药（回复 / 增益 / 净化，主动使用）
- 作用家族：回血、护盾、净化、攻击增益、保命。单次使用、占格、用完腾格。
- **可合成**：丹药走「同丹药类 + 同品质 → 升阶、类型随机」合成（见 §12），类型池 = 已天赋解锁的丹药池共享池（默认仅聚气丹，靠天赋解锁其余 4 种）；合成后数值提升，可能出现池内任一类。`[P]`
- 详细名册与 Q1–Q9 效果数值见 **P1-4**。

### 7.3 符咒（进攻 / 减益，主动使用）
- 作用家族：直接伤害、定身、破甲、减攻、易伤。单击 → 使用钮生效。
- **可合成**：符咒同样走「同符咒类 + 同品质 → 升阶、类型随机」合成（见 §12），类型池 = 已天赋解锁的符咒池共享池（默认仅雷符，靠天赋解锁其余 4 种）；合成后数值提升，可能出现池内任一类。`[P]`
- 数值独立：符咒效果**不享受武器攻击倍率 / 境界倍率**，走独立数值 `[P]`（见 P1-5）。
- 详细名册与 Q1–Q9 效果数值见 **P1-5**。

> 丹药 / 符咒来源：场上随机奖励（取自已天赋解锁的丹药池 / 符咒池）+ 肉鸽 3 选 1 可含消耗品（待定，默认场上奖励主来源）。**每个消耗池默认仅 1 件（聚气丹 / 雷符），靠天赋解锁更多类型**，与法宝 / 护甲池同构；聚气丹与雷符是默认入池类型，不是开局直接放入部署格的实体道具。

## 8. 怪物系统

### 行为规格
- **近战怪**：向下移动 → 到第 7 行（底线）进入**蓄力 1 回合** → 下回合攻击玩家。被挡时待机不攻击。
- **远程怪**：射程 **3 格**，**移动中攻击（先攻击后移动，不停留）**；只要处在射程范围内就会在远程攻击阶段出手。到底线后不会切换为近战蓄力，而是在后续移动阶段越界离场。被前方怪物挡住时**仍可远程攻击**。
- 参考：砰砰法师「豌豆射手每回合移动 1 格并远程攻击」。

### 阻挡规则
- **阻挡（当前实现）**：怪物移动只检查其他怪物占位（一格一怪）；场上随机奖励不阻挡怪物移动，但顶行奖励会占用该列刷新点，避免新刷怪物与奖励同格。
- 底线蓄力/攻击中的怪物挡住后方同列怪物。
- **级联前进**：前排死亡腾位，同列后方怪物**同回合各前进 1 格**（从底向顶处理）。
- **定身影响**：受「定身」的怪物停移，其停留回合不触发级联前进；解除定身后按正常节奏继续推进。

### 玩家负面状态（怪物施加）
敌人可对玩家施加减益，触发「净化 / 免疫」类护甲（净秽宝珠）与丹药（清心丹）的战略价值。减益类型与 §15.4 同构（离散可结算，**无减速**）：

| 减益 | 对玩家影响 | 施加者（建议，待定） |
|------|-----------|---------------------|
| 减攻 | 玩家所有法宝伤害 -X%（持续 N 回合） | 白袍法师（合体·远程）、青蛇妖（金丹·远程） |
| 定身（封印） | 随机 1 格法宝停摆 N 回合（无法攻击 / 生效） | 紫袍修士（渡劫·远程）、提灯侍女（合体·远程） |
| 易伤 | 玩家受击伤害 +X%（持续 N 回合） | 紫袍修士、狐火妖女（化神·远程） |

- 施加时机：在 §4 第 9 步「怪物攻击」结算后，按怪物技能表附带施加（非所有怪物都会施加）。
- 幅度 / 持续 / 施加频率全为 `[P]`，需 playtest 定标。
- 清除以「净化（净秽宝珠 / 清心丹）」或「免疫（净秽宝珠 / 清心丹）」处理；玄铁宝盾提供格挡 / 反弹，不提供负面免疫；与武器对怪的减益体系完全对称。

## 9. 场上随机奖励系统
- 场上随机奖励是当前实现中的补给来源；怪物死亡只发修为，不直接生成宝箱。
- 奖励按概率 / 保底 / 肉鸽奖励等机制从顶部或备用空格刷新；同一时间场上最多 2 个。
- 奖励每回合下移 1 格；到第 7 行当回合仍可被武器击碎，当回合未击碎则下回合移动阶段越界消失。
- **阻挡规则（当前实现）**：奖励移动时只与其他奖励互相阻挡；怪物移动时只与其他怪物互相阻挡。奖励不会阻挡怪物移动，怪物也不会阻挡奖励移动。
- **刷新点规则（当前实现）**：顶行已有奖励时，会占用该列刷新点，怪物波次刷新会避开该顶行奖励，避免新刷怪物与奖励同格重叠。
- 暂存区满时击碎奖励：新道具会与暂存区现有道具比较品质；若新道具品质更高，则替换暂存区旧道具，否则新道具不存入，奖励消失。
- 补给内容：法宝从「已天赋解锁的攻击池」掉；护甲道具从「已天赋解锁的防御池」掉；丹药从「已天赋解锁的丹药池」掉；符咒从「已天赋解锁的符咒池」掉（四类池均默认 1 件、靠天赋解锁扩池）。

### 12.2 合成规则（随机类型盲盒 —— 已解锁的类型共享池，按定义权重抽取）

合成判定（拖动 A 到同大类、同品质的 B，耗 1 回合）：
```
2 × 同大类（法宝武器 / 护甲道具 / 丹药 / 符咒）+ 同品质
  → 1 × 同大类、品质 +1、类型随机（从「该大类已天赋解锁的类型共享池」抽取）
  → 权重：当前实现读取道具定义中的 `weight`（若缺省则使用 `spawnChance`，再缺省为 1）做加权随机；当前大多数可入池定义 `weight = 1`，因此现状表现接近等概率，但机制层支持非等权扩展
  → 圣品（Q9）为绝对上限，不可再合成
```

**四类池的定义（关键，全部同构）**：
- **攻击池（法宝）** = 所有「已天赋点出的武器流派」具名武器之**并集（共享）**：
  - 例：只解锁青锋剑 → 池 = {青锋剑}，Q1 青锋剑 + Q1 青锋剑 必出攻击池中的已解锁武器；若后续解锁碧水剑 / 太极剑且三者权重均为 1，则三者近似等概率。
  - 例：再解锁赤焰枪 / 破阵枪 → 池 = {已解锁剑系武器 + 赤焰枪, 破阵枪}；若这些定义权重均为 1，则按已解锁件数近似等概率抽取。
- **防御池（护甲道具）** = 所有「已天赋解锁的护甲类型」之并集，规则同上，按定义权重抽取；当前权重多为 1，现状近似等概率：**默认仅玄铁宝盾**，其余 4 件靠天赋解锁扩池。
- **丹药池** = 所有「已天赋解锁的丹药类型」之并集，规则同上，按定义权重抽取；当前权重多为 1，现状近似等概率：**默认仅聚气丹**，其余 4 种靠天赋解锁扩池。
- **符咒池** = 所有「已天赋解锁的符咒类型」之并集，规则同上，按定义权重抽取；当前权重多为 1，现状近似等概率：**默认仅雷符**，其余 4 种靠天赋解锁扩池。
- **初始默认池与开局道具**：开局默认解锁 **青锋剑**、**玄铁宝盾**、**聚气丹**、**雷符** 四个基础类型；但实际开局只在部署格放置 **1 把青锋剑**。碧水剑 / 太极剑不是默认池内容，需要沿天赋树剑修支线逐个解锁。玄铁宝盾 / 聚气丹 / 雷符进入掉落与合成池，需通过后续场上随机奖励或合成获得；其余类型靠天赋点逐步解锁扩池。
- 未解锁的类型绝不会出现在合成结果 / 掉落中。

- 缓解机制：分解免费兜底 + 错位类型可继续当材料升阶（圣品封顶，不会卡死）。

### 12.3 类型池来源（全部天赋驱动，默认各 1 件）
1. **法宝（攻击池）**：当前天赋树按单把武器逐个解锁，而不是按流派一次性解锁整组；默认仅青锋剑在攻击池中。玩家沿武器分支购买赤焰枪 / 破阵枪 / 碧水剑 / 太极剑 / 缚妖链 / 双刃锁链 / 镇妖塔 / 护心珠 / 法修六件等节点后，对应武器分别进入攻击池共享池。
2. **护甲（防御池）**：天赋树解锁护甲类型（玩家主动）→ 该护甲进入防御池共享池；默认仅玄铁宝盾，天赋解锁 荆棘战甲 / 玉清道衣 / 生生造化袍 / 净秽宝珠。
3. **丹药（消耗池）**：天赋树解锁丹药类型 → 进入丹药池共享池；默认仅聚气丹，天赋解锁其余 4 种（节点清单见 **P3.3 ③**）。
4. **符咒（消耗池）**：天赋树解锁符咒类型 → 进入符咒池共享池；默认仅雷符，天赋解锁其余 4 种（节点清单见 **P3.3 ④**）。
> 天赋树完整节点、成本、A/B 变种增益与购买时机见 **P3** 整节。

### 15.4 回合制效果分类（无「减速」概念）
离散回合制里敌人每移动阶段固定走 1 格，"减速"无字面意义；所有原迟缓效果改为以下回合制合法效果：

| 类型 | 回合制定义 | 软硬 / 类别 |
|------|----------|-----------|
| **定身 / 冻结** | 连续 N 个移动阶段不前进（停移）；远程怪定身期间仍可在其攻击阶段出手（先攻后移），近战则完全不动 | 硬控 |
| **击退** | 立即上移 1 格（争取距离 / 回合） | 位移 |
| **拉拽** | 把最近敌人拉近 1 格 | 位移 |
| **破甲 / 减防** | 目标防御值 -X%（持续 N 回合），对怪物防御值生效 → 受击更痛 | 减益（进攻向） |
| **减攻** | 目标攻击力 -X%（持续 N 回合），怪物攻击玩家时伤害降低 | 减益（防守向） |
| **减暴击** | 目标暴击率 / 暴伤 -X%（持续 N 回合），削弱高威胁敌人爆发 | 减益 |
| **易伤 / 标记** | 被标记者受到伤害 +X% | 减益（易伤） |
| **灼烧 / 中毒 / 流血** | 每回合受到 X 点持续伤害，持续 N 回合 | DoT（伤害类） |

- 原「迟缓（半速）」的战略意图 = 降低敌人有效输出 / 争取回合，**已被减攻（直接削攻击）与定身（直接停移）完全覆盖**，且均离散可结算，无"速度"歧义。
- 减益可通过「持续 N 回合 + 每回合 -X%」精确结算；DoT 通过「每回合末结算 X 点」精确结算。
- **玩家侧对称**：玩家也可被施加「减攻 / 定身（封印）/ 易伤」三类减益（见 §8），由净秽宝珠 / 清心丹 净化或免疫处理。

### 1. 品质-伤害主曲线（baseDamage）
`baseDamage` = 武器单发伤害基准。每升 1 品质 ×2，Q1→Q9 总跨度 256×，与 2ⁿ 合成成本严格同阶（1 件 Q9 需 256 件 Q1，单局实际可达 Q5–Q7）。

| 精品 | 4 | 96 | 8 |

### 2. 各模式攻击 profile 与品质演进
> 以下以「该模式代表武器」说明机制；所有 15 把武器套用对应模式 + 自身类型系数（§15.3）。

#### 单体（青锋剑 / 碧水剑 / 太极剑 / 白骨杖）
- 伤害 = `baseDamage × 类型系数 × 境界攻击倍率`。
- **暴击（仅青锋剑，属「特效」，Q5 起）**：Q5 15%×2.0 ｜ Q6 20%×2.0 ｜ Q7 专属「剑心通明」必暴×2.0 + 击杀溢出穿透 ｜ Q8 必暴×2.5 + 溢出 1 敌 ｜ Q9 必暴×2.5 + 溢出整列。
- 碧水剑追加「减攻（目标攻击 -X% N 回合）」、太极剑追加「击退 1 格」、白骨杖追加「减防（目标防御 -X% N 回合）」——三者均为 **Q5 起**的附加特效（Q1–Q4 不触发）。

#### 穿透（赤焰枪 / 破阵枪）
- 最近目标 = `baseDamage × 0.90`；穿透后方 `pierceCount` 敌，每个 `× 0.8ⁿ`。
- **pierceCount 演进（穿透属「伤害送达方式」，Q1–Q4 最小基础值）**：Q1–4: 0（仅打最近 1 敌）｜ Q5: 1 ｜ Q6: 2 ｜ Q7: 整列（专属「破阵无双」/「燎原」觉醒）｜ Q8–9: 整列（数值强化）。
- 赤焰枪追加灼烧 DoT（Q5 起）；Q7+ 改为**命中时扩散灼烧**（而非每回合末递归传播），Q9 可扩散至全场。
- 破阵枪追加破甲（Q5 起）：表现为**本武器命中即时无视目标部分防御**；Q7+ 追加易伤标记。破阵枪不挂「持续无视防御」状态，以避免与白骨杖的持续减防定位重叠。

#### 横扫（青羽扇 / 清音琴 / 双刃锁链）
- 主目标 = `baseDamage × 系数`；相邻列各最近 = `baseDamage × splashRatio`。
- **splashRatio（溅射属「伤害送达方式」，Q1 起最小基础值）**：Q1–2 30% ｜ Q3–4 40% ｜ Q5–6 50% ｜ Q7–8 60% ｜ Q9 80%。
- 青羽扇追加「风刃印记」、清音琴追加「定身」、双刃锁链追加「拉拽」——三者均为 **Q5 起**的附加特效（Q1–Q4 仅裸横扫伤害）。
- 清音琴 Q7+ 的「镇魂魔音」按当前实现为：被清音琴定身的目标在定身期间**每回合首次受到法宝伤害时**触发一次震荡追加伤害；不按「每次受击」无限触发，以控制多武器集火下的乘算膨胀。

#### 范围（紫气葫芦 / 金光环 / 灵墨笔 / 镇妖塔）
- 最近目标 = `baseDamage × 系数`；AoE 内敌 = `baseDamage × 0.5`。
- **AoE 半径（属「伤害送达方式」，Q1 起最小基础值）**：Q1 同列前后各 1 格 ｜ Q5 扩至相邻列同排 ｜ Q7 3×3 ｜ Q9 全场。
- 紫气葫芦追加「中毒 DoT」、金光环追加「范围减攻」、灵墨笔追加「易伤标记」、镇妖塔追加「范围减攻压制」——均为 **Q5 起**的附加特效（Q1–Q4 仅裸范围伤害）。
- 紫气葫芦 Q7+ 的「万毒归宗」会给中毒目标挂毒爆标记；目标后续死亡（包括死于 DoT）时触发一次范围毒爆。毒爆每个死亡目标最多触发一次，不做无限连锁。

#### 控制（缚妖链）
- 单体伤害 `baseDamage × 0.90` + **定身（Q5 起特效）**：目标连续 N 个移动阶段不前进；Q1–Q4 仅裸单体伤害。

#### 守护（护心珠）
- 范围持续伤害 `baseDamage × 0.80` + **范围减攻（Q5 起特效）**：范围内敌攻击 -X% N 回合；Q1–Q4 仅裸范围持续伤害。
- **减攻演进（Q5 起）**：Q5 减攻 2 回合(单体) ｜ Q6 3 回合 ｜ Q7 专属「护世莲心」全场 + 减攻 -25% ｜ Q8 减攻 -30% ｜ Q9 减攻 -35%。

### 3. 最终伤害公式
```
finalDamage = baseDamage(品质)
            × 类型系数（§15.3 各武器值）
            × 境界攻击倍率（§10）
            × (1 + 肉鸽增伤%)
            × (1 + 天赋增伤%)
            × 暴击倍率（若触发，单体基准线 Q7+）
```
- 攻击频率 = 每回合 1 次；多武器按列独立结算、叠加。
- 横扫/范围的溅射/AoE 在「各列最近 / 范围敌人」上应用同公式。
- 减益（减防/减暴击/易伤）独立于本公式，作为「目标结算前修正」影响后续伤害。

### 4. 与现有玩法耦合
| 现有系统 | 武器数值如何接入 |
|---------|----------------|
| 目标优先级（§5 距离优先） | 单体/穿透走同列最近；横扫/范围按「各列最近 / AoE」扩展 |
| 合成随机类型盲盒（§12，四类池共享 + 按定义权重抽取） | build 围绕已天赋解锁的流派 / 护甲 / 丹药 / 符咒共享池规划；错类型分解兜底 |
| 场上随机奖励（§9） | 四类道具均从已天赋解锁的对应池随机给类型 |
| 境界攻击倍率（§10） | 全局乘算，高境界武器显著更强 |
| 肉鸽奖励 / 天赋 | 可放大某流派或全局（如「剑修 +15%」「横扫 +1 列」「减益 +20% 时长」） |
| 圣品上限（§12） | Q9 数值封顶 |
| 防御结算（§6） | 破阵枪/白骨杖可削怪物防御值，与怪物防御形成攻防博弈 |
| 玩家负面状态（§8） | 净秽宝珠 / 清心丹 净化或免疫怪物施加的减益，与武器减益体系对称 |
| 回合制效果（§15.4） | 定身=停移 N 阶段；减攻/减防/减暴击/易伤/DoT 均为离散可结算减益；**迟缓已移除** |

### 5. 平衡假设
- 怪物 HP / 攻击力 / 防御值 / 暴击 已定义于 P1-6。当前实现先保留原型怪物表，不随翻倍武器曲线自动等比放大；正式平衡需通过 playtest 决定是否提高怪物 HP / DEF、难度倍率或波次压力。
- 类型系数（0.75–1.0）刻意不等：纯 DPS 青锋剑最高，但横扫/穿透/范围靠机制在多场景反超，避免「一种武器通吃」。

### P1-6.4 怪物防御减伤规则 & 破甲博弈

- 武器对怪伤害：`effectiveDmg = max(1, rawWeaponDmg − DEF_eff)`。
- **DEF_eff 上限（防极端叠防）**：`DEF_eff = min(monsterDEF, rawWeaponDmg × 0.5)`——怪物防御最多削减武器伤害的 50% `[P]`，保证攻击永远有效。
- **破甲 / 减防武器**（§15：白骨杖 / 破阵枪 / 破甲符 / 削防类）临时降低 `monsterDEF` → `DEF_eff` 下降 → 更多伤害穿透。
- **示例（R5 化神，普通怪，青锋 Q5 = 269 伤害，怪 DEF 37）**：
  - 裸打：DEF_eff = min(37, 134.5) = 37 → 实际 232（减伤 14%）。
  - 白骨杖 Q7（−25% 防御）→ DEF 27.75 → 实际 241（约 +4%）。
  - 破阵枪 Q9（完全无视防御）→ DEF 0 → 实际 269（约 +16%）。
  - → 翻倍曲线下，当前怪物 DEF 表的破甲收益会低于旧锚点；若希望破甲继续保持 10%–43% 显著收益，后续需重标怪物 DEF 或提高高境怪防御权重。

### P1-6.8 调平复核 / "broken" 判定

**逐境界清空验证（单列最坏情况，on-pace 玩家 Q=R 武器）**

| 境界 | 普通怪 HP | 单列实际 DPS（−DEF） | 清空回合 | 抵达攻击位回合 | 结论 |
|---|---:|---:|---:|---:|---|
| 1 | 50 | 12−4=8 | 6.3 | 7 | ✅ 抵达前清掉 |
| 3 | 160 | 58−12=46 | 3.5 | 7 | 偏快，需实测 |
| 5 | 500 | 269−37=232 | 2.2 | 7 | 偏快，需实测 |
| 7 | 1500 | 1229−113=1116 | 1.3 | 7 | 明显偏快，需重标 |
| 9 | 4500 | 5530−342=5188 | 0.9 | 7 | 明显偏快，需重标 |

→ 翻倍武器曲线下，当前怪物 HP/DEF 表在中后期会被 on-pace 单列武器快速清空；实战因横扫/范围/穿透溢出更宽松。保留当前实现值用于原型验证，但正式平衡需要通过 playtest 决定：提高高境怪物 HP/DEF、增加波次压力，或降低高品质掉落/合成速度。**精锐 / 头目 HP 显著更高（×2–×3），仍需要多武器聚焦 / 减益 / 控制 / 护甲 + 丹药兜住**。

**"broken" 判定阈值（playtest 前先定义）**

- **过易（broken-easy）**：普通怪被「落后 1 品质武器（Q=R−1）」在 ≤2 回合清空 → 数值需上调。
- **过难（broken-hard）**：普通怪被 on-pace Q=R 武器清空 >12 回合，或 board 被同列堆积怪冲破 → 数值需下调。
- **护甲失效（broken-trivial）**：玩家满甲 + 满药时，怪物 ATK 实际占比 <5% 最大气血，游戏无死亡压力 → 需提高 ATK 或收紧护甲 DEF 上限（§6 的 60% 上限 / 本节的 DEF 50% 上限）。
- **破甲失效（broken-useless）**：即使完全无视防御，对怪伤害提升 <10% → DEF 基准需下调。
- **远程过强**：远程怪因移动中攻击，实际 DPS 远超近战同 tier → 需加大 HP×0.8 / ATK×0.85 补偿或加刷新延迟。

## P1-7 肉鸽 3 选 1 奖励池（构筑型 modifier）

> 把「每突破 1 境 → 3 选 1」的局内构筑事件落成**可直用的奖励池**，放大既有的武器 / 护甲 / 减益 / 消耗品框架（P1-1~P1-6），制造「本次突破该强化哪条 build 线」的决策。奖励均为 **run-scoped modifier**（局终 / 轮回清空，不跨局）。
> **设计铁律**：① 每条奖励 = 一个**独立玩法杠杆**（不同机制），禁止「同杠杆不同数值」重复条目；② 含「击杀修为」的奖励**一律删除**（击杀本就给修为，§10/P1-6.2）；③ 补给类按**回合**发放，不以境界为单位；④ 奖励出现前提 = 玩家已将该类法宝 / 护甲 / 消耗品**解锁进对应合成池**，未解锁则从不进入候选。

### P1-7.1 触发与节奏（cadence）

| 项 | 规则 |
|---|---|
| 触发时机 | 每次**境界自动突破成功**（修为满 → 自动突破 → 即时生效）后，弹出 3 选 1。 |
| 触发范围 | 突破至 **第 2 境 ~ 第 9 境**（开局已在炼气境，不触发）；单局最多 8 次。 |
| 跌境重领 | 筑基及以上**跌境**（倒退 1 级）后重新突破同境 → **可重领**一次（解决「中途挫折丢构筑」的挫败感，符合进度模型「跌境不清空」）。 |
| 单局不重复 | 已领取的奖励 **ID 本局内不再出现**（避免同类叠满 / 强迫重复）；池约 25 条，8 次事件不会耗尽。 |
| 是否可跳过 | **必须选 1**（无跳过钮）——保节奏、逼决策；若 3 项均不想要，设计上保证至少 1 项属「攻势 / 守势」兜底线（见 P1-7.2）。 |

### P1-7.2 出牌机制（offer 规则）

```
突破成功 → 先按「玩家已解锁内容」过滤候选池（见 P1-7.4 前提列），仅保留当前可生效条目：
  ① 分类多样性强制：3 项中 **至少 2 项来自不同大类**（攻势/守势/控场/资源/续航/特异），避免一手全攻势或全资源；
  ② 幂阶加权：当前境 R 低（2~4）→ 偏向「小/中」幂阶；R 高（5~9）→ 允许「大」幂阶出现权重上升；
  ③ 不重复 ID（同一次 offer 内 3 项 ID 互异，且排除本局已领）；
  ④ 兜底：若过滤后随机结果 3 项全非攻势/守势，强制把其中 1 项替换为「攻势或守势」小幂阶条目；
  ⑤ 空池保护：若某大类因未解锁导致候选不足，从其他已解锁大类补足，绝不出现「无可选」或「给了用不上的奖励」。
玩家点选 1 项 → 即时生效（叠加到 run modifier 集合）→ 继续游戏。
```

### P1-7.3 量级与境界缩放

- 各奖励标称量级为该条「基准值 `[P]`」；**高境（R≥5）反转的同一类奖励，量级按 `+15%×(R−4)` 线性上浮**（如 R7 的「全武器 +12%」实际 +15.6%），保证后期奖励仍跟得上武器 ×2/品质 的曲线。
- **大幂阶条目**（不灭 / 道心通明 等）**不缩放**（已是终局级，避免叠加失控）。

### P1-7.5 叠加规则（stacking）

- **同类 % 加法**：不同 ID 的同一维度 % 可叠加（如 O1 全武器 +12% 与 O2 流派 +18% 分属「全局 / 流派」两维度，互加）。同一 ID 本局不重复（P1-7.1）。
- **跨维度乘算**：`实际武器伤害 = 基础 × (1 + Σ全武器%) × (1 + Σ流派专精%) × 境界攻击倍率 × (1+天赋增伤) × (1+暴伤)`；护甲 / 减益 / 资源 / 续航各自独立维度，互乘不互加。
- **绝对数值类**（穿透 +1 / AoE +1 格 / 每 5 回合 +1 消耗品 / 击杀回 N% 血）直接加法，无上限但受「单局不重复」约束（每种至多取 1 次）。
- **大幂阶条目**（带「且」的双效）两段分别并入对应维度。

### P1-7.6 "broken" 判定（playtest 前先定义）

- **过强（broken-OP）**：全局武器伤害叠加 > +80%，或单流派专精 > +60% → 单列武器秒清头目（P1-6.8 头目需多武器聚焦的预期被破坏）→ 处理：同类 % 设叠加软上限（全武器最多取 3 次 / 流派最多取 2 次），或下调 O1 量级。
- **资源失控（broken-loot）**：场上奖励出现率 / 品质权重叠加过高 → 奖励溢出、护甲/消耗品通胀 → 处理：E1/E2 设总加成上限 +50%。
- **控场锁死（broken-cc）**：定身相关叠加使怪物连续停移 > 4 阶段 → 怪物变木桩无威胁 → 处理：C1 与清音琴/缚妖链专属特效的定身阶段合计设 ≤5 上限。
- **构筑死锁（broken-stall）**：若某次 offer 经解锁过滤后 3 项全为非攻势/守势、玩家无战力可拿 → 违反 P1-7.2④ 兜底 → 实现层强制替换，设计层不Occur。
- **真空期（broken-gap）**：8 次事件间跨度过长（如某境波次极长无突破）→ 玩家感不到成长 → 处理：确保每境波次可在合理时间内达成突破（见 P2 波次编排）。

### P1-7.7 与既有系统耦合

- **与武器曲线（P1-1）**：攻势类放大 `baseDamage × 系数`，量级锚定「普通怪 HP = 4×DPS」的 buffer（P1-6.8），+12%~+18% 在合理带内，不破坏「普通怪抵达前清空」。
- **与护甲（P1-3）/ 气血（§10）**：守势类放大防御值 / 最大气血，需对照 P1-6「护甲失效」阈值（玩家满甲满药时怪 ATK 实际占比 <5% → 收紧）。
- **与减益（§15.4）**：控场类放大定身阶段 / 减益幅度，需对照减益幅度 playtest 定标（P4.1），避免减攻叠满后怪物零威胁。
- **与场上奖励（§9）**：资源类改变奖励刷新与品质节奏，间接影响护甲/消耗品供给，需监控 broken-loot。

## P2 关卡与波次设计（P1-6.7 预算 → 具体波次编排）

> 把 P1-6.7 的「每境界累计刷怪预算」落成**具体逐波组合 + 刷新间隔**，并**复核修为奖励能否撑起 §10 突破节奏**。
> 所有数值标 `[P]` 为 playtest 前假设；波次编排为「设计骨架」，列位分配为示意（实现层可随机化列号）。

### P2.1 关卡结构总览

- **局（Run）** = 从 炼气境 一路推进到 渡劫境 的一整轮；当前主流程已在渡劫境最终波全部清空后判定通关/飞升，轮回入口仍处于函数预留状态。
- **境界 = 关卡（Level）**：9 个境界即 9 关，顺序递进；每关含若干**波次（Wave）**。
- **通关一关的条件**：累积**修为达 §10 该境阈值** → 自动突破（§10，即时、全额回血、修为清零）→ 进入下一境，**清空棋盘残留怪物 / 场上随机奖励并重置本境波次状态**，并触发肉鸽 3 选 1（P1-7）。
- **渡劫境（R9）= 终局关**：无后续突破阈值，波次以**紫火老修（头目）**收尾即通关/飞升。
- 跌境（筑基+ 死）后回到本关波序**起点**重打（修为清零、气血恢复，构筑保留，见 §13）。

### P2.2 波次机制（cadence）

- **刷新时机**：回合结算第 14 步（§4）按本关波序刷新下一波。
- **波间隔**：**3 回合 `[P]`**（R1 教学期放宽至 **4 回合 `[P]`**）；即每 3 回合新刷一波。
- **每波队列规模（当前实现）**：每波按修为预算生成待入场队列，队列上限为 `Config.WAVE_MAX_MONSTERS = 10`；难度 3+ 的额外怪会在预算队列基础上追加。实际入场不是一次性全部刷出，而是进入 `pendingWaveQueue` 后按批次刷新。
- **入场批次与场上上限（当前实现）**：炼气/筑基同时活跃怪上限约 1，只刷 1 只；金丹/元婴上限约 3；化神及以后活跃上限约 5。每次实际刷新批量为 1~3，只在炼虚及以后可到 1~4，并受剩余活跃槽位限制。
- **突破清场**：突破成功瞬间清空棋盘所有怪物与场上随机奖励，下一境波序从第 1 波重新开始。
- **难度词条接入**：难度 3+「每波额外 +1 怪」= 每波从本境池随机补 1 只；难度 4/5 追加敌攻 / 场上奖励出现率词条（§14），波次构成本身跨难度不变，仅怪物**数值**缩放（P1-6.6）。
- **每局随机性（当前实现）**：具体怪物实例、列位、Boss 落点使用全局 `math.random()`；`runSeed` 字段会在开局记录，但当前尚未接管为确定性随机种子，因此它只作为调试 / 记录字段，不能保证同 `runSeed` 完全复现。**骨架（波数/修为份额/里程碑锁/Boss 身份）跨难度与跨局一致**，保证玩家对关卡有关键记忆点，但每局遭遇的怪组合不同。

### P2.4 每境界波次编排（随机骨架）

> **设计基调**：逐波表不写死具体怪物，改为 **「固定骨架 + 实例随机」** 的随机生成。当前代码记录 `runSeed` 但尚未用它初始化独立 RNG；实际随机来自全局 `math.random()`，因此本节为当前生成规则说明，不承诺同种子复现。
> 三层确定性保底、三层随机性抖动，二者不冲突：
>
> | 维度 | 确定性（固定） | 随机性（每局 roll） |
> |---|---|---|
> | 教学里程碑 | 首精锐/首远程/首肉盾/debuff 首登场 **锁定对应怪必出** | — |
> | 修为经济 | 每关总修为、每波修为份额 **固定**（沿用 P2.3 对账值） | 仅在区间内换具体怪，不破突破节奏 |
> | 关卡结构 | 波数、波间隔、Boss 身份（虎妖/紫火）固定 | Boss **落点波次**在末期窗口随机 |
> | 怪物实例 | 角色模板（每波几只什么 tier/什么机制标签）固定 | **具体哪只同类怪**随机抽 |
> | 列位布置 | 防溢软规则（同列 ≤1 只，规模>5 才叠）固定 | 每怪随机分配列（负载均衡） |
> | 种子 | 开局记录 `runSeed` | 当前未用于确定性 RNG，复现能力尚未接入 |

#### P2.4.2 刷新随机算法（spawn algorithm）

```
生成一关 R（载入 P2.4.1 的四表；随机使用当前全局 math.random，runSeed 仅记录）:
  bWave = (R 为终局) ? N : random(Boss窗口[a,b])   // Boss 落点随机
  for w in 1..N:
    预算 = shares[w]
    if w == bWave:
       生成 = { 固定Boss身份 } + 从候选池随机抽 escort（补足预算±8%，满足规模/列均布 ）
    elif (w, forced) in 里程碑锁:
       生成 = { forced 必出 } + 从候选池随机补其余槽（补足预算±8%）
    else:
       生成 = 从候选池按「角色模板」随机抽（模板=该波几只什么标签，见下；补足预算±8%）
    列位 = 该波每怪随机分配列（负载均衡：优先空列，同列≤1，规模>5 才允许叠）
  输出本关逐波实例（每局不同，修为总额尽量贴近 P2.3 目标）
```

- **角色模板（每波固定，类型随机）**：沿用原逐波表的「数量×tier/标签」骨架。例 R2 W3 = `普通×2 + 精锐×1`，原表写死`灰狼妖×2+黑狼妖×1`，现 = `随机普通×2 + 黑狼妖×1`（黑狼妖为锁定）。R6 W7 = `重型肉盾×5 + 普通×2 + 普通×3`，原写死火焰石人×5+持刀×2+驯兽×3，现 = `火焰石人×5(锁定首重型) + 随机普通×5`。
- **预算兜底**：若随机抽怪修为偏出 ±8%，实现层用「同 tier 另一只」替换微调（pool 内同类修为相近，易收敛）；偏差仍超阈值则下调该波边缘怪数量（不影响里程碑锁与 Boss）。
- **防溢出**：列位随机后仍触发 P2.2 防溢软规则（某列≥7 顺延 1 回合）。

### P2.7 "broken" 判定

- **波次过密（broken-flood）**：某列同时存活 >7 怪且玩家清不掉 → 当前刷新列选择会避开达到列软上限的列，同时有活跃怪上限；若仍冲破底线，下调波间隔、每波队列上限或活跃上限。
- **真空期（broken-gap）**：两波间隔过长（玩家无怪可打、无决策）→ 波间隔 >5 回合即预警，R1 教学期例外。
- **修为断档（broken-stall）**：清完本关所有波次修为仍未达阈值（bar 差 >10%）→ 需补波或上调击杀修为（已用 P2.3 对账预防，playtest 复核）。
- **Boss 过肉（broken-tank）**：头目在预期聚焦下仍 >15 回合未被清 → 头目 HP ×3 倍率需下调或给更多减益窗口。
- **随机破坏教学（broken-rng-onboard）**：roll 出的实例**未含里程碑锁定怪**（实现层漏锁）→ 新手引导断点 → 硬性断言：里程碑锁的 `(波, 必出怪)` 在 spawn 算法中不可被随机覆盖，生成后校验必出怪存在。
- **随机破预算（broken-rng-budget）**：某波 roll 修为偏离份额 >8% 且预算兜底失败 → 突破节奏抖动 → 处理：超阈值则该波边缘怪数量 −1 重算，仍超则回退该波为确定性骨架（保经济优先于随机）。

## P3 天赋树设计（解锁 / 流派变种）

> **设计定位（按当前实现）**：天赋树使用 `talentPoints` 购买节点，天赋点与已购买节点 / modifier / A-B 变种 / 解锁池在重开与放弃本局时按永久资源保留；解锁节点会把法宝 / 护甲 / 丹药 / 符咒类型写入对应共享池，影响后续合成与场上随机奖励。肉鸽奖励仍是 run-scoped modifier，负责本轮构筑放大。
> - **当前实现结构**：`TalentDefs.lua` 只有 4 个页签分支：法宝 / 护甲 / 丹药 / 符咒。通用数值节点并非独立分支，而是放在法宝页签中形成一条线性主干，并同时承担「通用强化」与「打开武器支线」的前置作用。
> - **与肉鸽池的边界（当前实现）**：肉鸽 3 选 1（P1-7）= **「放大已有 build」**；天赋树 = **「决定 kit + 提供确定性基础强化」**。当前天赋树已经包含全武器伤害 / 暴击 / 受击减伤 / 护甲值 / 最大气血 / 回春等通用数值节点，因此与肉鸽池存在部分同杠杆叠加，需按 P3.6 监控 double-dip。
> - **与 §13 / §14 耦合**：点来源 = 每次自动突破（基础 1 + `reincarnationCount` + `difficultyTalentBonus`）；当前 `Config.DIFFICULTY[x].talentBonus` 尚未自动写入 `difficultyTalentBonus`，因此默认难度 1 下只受基础点与轮回次数影响。

### P3.1 点经济（当前实现）

每次自动突破获得点数 = `1（基础）+ reincarnationCount + difficultyTalentBonus`。从炼气境到渡劫境最多触发 8 次突破奖励（突破至第 2 境 ~ 第 9 境）；默认难度 1 下 `difficultyTalentBonus = 0`。天赋点上限为 59。

| 轮回 r ＼ `difficultyTalentBonus` | +0 | +1 | +2 | +3 | +4 |
|---|---:|---:|---:|---:|---:|
| **r0** | 8 | 16 | 24 | 32 | 40 |
| **r1** | 16 | 24 | 32 | 40 | 48 |
| **r3** | 32 | 40 | 48 | 56 | 59（封顶） |
| **r5** | 48 | 56 | 59（封顶） | 59（封顶） | 59（封顶） |
| **r7+** | 59（封顶） | 59（封顶） | 59（封顶） | 59（封顶） | 59（封顶） |

- 单次从 0 点开始的新增点范围约 **8 ~ 59**（受上限封顶）。树全买满约需 **44 点**（见 P3.3 成本合计），故 r0 / `difficultyTalentBonus=0` 只能购买主干与少量解锁；高 r 或外部写入较高 `difficultyTalentBonus` 时可接近全解锁。
- **当前实现的树结构**：通用数值主干 6 节点放在法宝页签内，且呈线性前置；武器不是按流派一次性解锁，而是沿主干分叉后按单把武器逐个解锁。效果：玩家需要在「先推进通用主干 / 打开某把武器 / 点 A/B 变种 / 扩护甲丹药符咒池」之间争同一笔点。
- 天赋点当前按永久点处理：重开 / 放弃本局会保留 `talentPoints`、`spentTalentPoints`、`purchasedTalents`、`talentModifiers`、`talentVariants` 与已解锁池；轮回函数不清空 `talentPoints`，且额外 +1。树节点购满后多余点受上限限制。

### P3.2 树结构总览（当前 4 页签 + 法宝线性主干）

```
天赋树（当前实现：天赋点/解锁池可跨重开保留）
├─ 法宝页签 weapon
│   ├─ 通用线性主干（6 节点，均 1 点）
│   │   └─ 煞气·攻击 → 锐气·暴击 → 罡气·减伤 → 铁骨·护甲 → 根骨·气血 → 回春·再生
```

- **节点类型**：① 单把武器解锁节点（1 点）② 护甲 / 丹药 / 符咒解锁节点（1 点）③ 变种节点（1 点，A/B 互斥）④ 法宝页签通用数值主干（1 点，线性前置）。
- **前置边**：当前实现不是“流派节点一次性解锁整组武器”，而是单把武器节点逐个解锁；通用数值主干本身也有线性前置，并作为武器支线入口。
- **互斥**：同一 `exclusiveGroup` 的 A/B 变种只能选择一个；其余节点可按前置关系购买。

### P3.4 A/B 变种设计原则（当前实现）

- 变种增益以 **机制向** 为主（暴击率/状态持续/位移格数/穿透数/定身阶段/特定武器幅度），通常挂在具体武器或武器小系上。
- 同一 `exclusiveGroup` 内 A/B 互斥，例如枪系 flame/break、剑系 sharp/soft、链系 lock/chain、塔系 suppress/soul、御系 light/protect、法系 offense/control。
- 当前通用主干已经提供通用 % 数值（全武器伤害 / 全武器暴击 / 受击减伤 / 护甲值 / 最大气血 / 回春），因此它与肉鸽 O1/D1/D6 等存在同维度叠加；playtest 须监控「通用主干 + 肉鸽同杠杆」的 double-dip（P3.6）。
- 所有数值 `[P]` 假设，playtest 前需与肉鸽池（P1-7.4）及武器曲线（P1-1）联合定标，确认「变种 + 通用主干 + 肉鸽」叠加后不触发 broken-OP。

### P3.5 购买 / 生效时机

- 点 **在突破瞬间入账**（§13）；玩家可在 **非战斗决策阶段**（回合结算前后）随时开天赋面板花费，突破后立即可用。
- 解锁节点生效后：**对应类型立即进入该大类共享池** → 影响后续合成盲盒（§12.2）与场上随机奖励（§9）的类型分布。
- 变种节点生效后：该流派武器战斗结算即套用新机制（如剑修·A 暴击率即时生效）。
- **不可退款**：已花点购买的节点，本局内不可撤销（局终清空重来）；分解/合成不影响已购节点。

### P3.6 与系统耦合 & "broken" 判定

- **耦合 §12 合成**：解锁更多类型 → 盲盒池更大 → 合成结果更不可预期（build 波动增大）；错位类型可继续当材料（圣品封顶）。
- **耦合 §9 场上奖励**：解锁更多类型 → 场上随机奖励可产出的种类更丰富（但权重偏低品质，见 P4.3）。
- **耦合 P1-7 肉鸽**：两者叠加放大 build；broken-OP 阈值（全武器伤 >+80% / 单流派 >+60% 等，见 P1-7.6）需把天赋变种一并计入监控。
- **broken-talent-spam（过配）**：高 r/高难单局点 ≥44 → 树被买满、build 趋同质 → 处理：树节点成本当前约 44，多余点受 59 点上限限制；局间方差交肉鸽池与难度乘率承担。
- **broken-talent-starve（饿配）**：r0/d1 仅 9 点，若玩家全点解锁而 0 变种/0 通用 → 有 kit 无强化 → 预期（早局本就该弱，靠肉鸽补强）。
- **broken-talent-doubledip（同杠杆 double-dip）**：法宝页签通用主干与肉鸽池（P1-7）在「全武器伤/护甲值/气血」上杠杆同维，叠加后若全局武器伤 >+80% 或护甲值加成 >+60% 或气血 >+60% → 触发 broken-OP（P1-7.6）→ 处理：下调 煞气·攻击/铁骨·护甲/根骨·气血 量级，或限定通用主干同类节点与肉鸽同类取高者（不叠加）。

### P4.3 消耗品使用上限 + 品质掉落分布

权重仅改防御值 baseline，特效仍按 P1-3 演进；合成升阶时权重作用于该品质基础值。数值 `[P]`，playtest 复核。

### P4.5 法修 A/B 变种分组

**决议：法修维持单分支双变种（攻向 A / 控向 B），不拆细。** 6 把法修武器已覆盖「横扫/范围/破甲/易伤/DoT/减攻」六类机制，拆成「扇修/琴修」会膨胀节点与池复杂度却无新机制增量（违背 minimum viable complexity）；A/B 分组已让两条路线手感分明（见 P3.3 法宝变种节点）。

### P4.6 收尾 "broken" 复核
- **debuff 死锁（broken-debuff-lock）**：任一减益使玩家持续 0 输出 >3 回合 → 处理：减攻封顶 −20%、封印随机轮换≤2 回合（P4.1 已保）。
- **词条通胀（broken-debuff-inflation）**：d5 叠加后玩家满甲仍被每回合秒杀 → 处理：词条不碰 DEF/暴击、有界（P4.2）。
- **奖励通胀（broken-loot-q）**：场上奖励直出 Q5+ 过多 → 处理：Q5 权重锁 1%，主要靠合成（P4.3）。
